# uplift-modelling

Scope: Explore simple models of AI adoption and coaching through an interactive mathematical explainer.

- Visibility: public; use illustrative scenarios, not private participant data.
- Google account: not needed.
- Still running or billing: GitHub Pages static hosting; no paid services or model calls.

Keep the explainer in `docs/`, with no build dependencies. Run `node --test tests/model.test.mjs` after changing model logic. Preserve the distinction between the expected value curve and a sampled binary-adoption history. Coaching expands reach; it does not mean teaching one task. Coaching responsiveness is an assumption to explore, not a fitted result.
