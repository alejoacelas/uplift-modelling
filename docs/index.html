03 / THE WHOLE MODEL

One gap drives progress.

growth in value=adoption rate×(reachable value − current value)

Progress slows as accessible opportunities run out. Low adoption can persist because some applications remain outside reach—not because everyone is slowly approaching the same destination.

See the equations and assumptions

Before coaching

g(t) = Vp (1 − e−λt)

g is expected value; V is available value; p is the reachable share. Everyone starts with zero adoption. λ = ln(2) / half-time.

Additional value after coaching

Δg(t) = Vδ (1 − e−λ(t−tc))

Applies after coaching at tc; before that, Δg = 0. The reachable share increases by δ, with p + δ ≤ 1. Total value is g + Δg.

  • Every reachable, unadopted application has the same constant adoption hazard λ. Coaching expands reach but does not change λ.
  • The grid uses exactly 100 equal-value applications, independent adoption clocks, and no abandonment. New applications get clocks starting at coaching.
  • The baseline and coached simulation share the same adoption times for originally reachable applications, isolating coaching’s added effect.
  • Benefits add up. There are no task dependencies, transfer effects, or changes in AI capabilities. Coaching’s effect is supplied, not explained.
  • Hours saved per week measure a flow. “Extra hours saved so far” is the area between curves, not the gap at a single date.
